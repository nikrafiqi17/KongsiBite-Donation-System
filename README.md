# KongsiBite Donation System - User Manual

## Introduction

This user manual provides comprehensive guidance on accessing, navigating, and utilizing the **KongsiBite Donation System**. The system is designed with two distinct user roles: **Administrator** and **User**. Each role is assigned specific permissions and functionalities to ensure efficient and secure system operations.

---

# Authentication and System Access

All users must authenticate through the unified login interface before accessing their respective dashboards.

## Login Procedure

1. Navigate to the system login page.
2. Select the appropriate user role.
   - **Administrator:** Click the **Admin Login** option.
   - **User:** New users must register before logging in.
3. Enter the registered **Email Address** and **Password**.
4. Click the **Login** button to access the appropriate dashboard.

## Registration

### Administrator

Administrator accounts are pre-configured within the system database. Self-registration is not supported.

### User

First-time users must create an account by selecting the **Register** option and completing the registration form before logging into the system.

---

# 1. Administrator Portal

The **Administrator Portal** enables administrators to manage user accounts, monitor donation activities, review donation submissions, and oversee the overall operation of the system.

## 1.1 Dashboard

The dashboard provides an overview of the system, including:

- Total registered users
- Total donations received
- Total donation amount collected
- Pending donation submissions

## 1.2 User Management

The **Manage Users** module allows administrators to:

- View registered user accounts
- Display each user's total donation amount
- Review individual donation histories
- Delete user accounts when necessary

## 1.3 Donation Management

The **Manage Donations** module enables administrators to:

- View donation summaries based on donation locations
- Monitor all donation records

## 1.4 Donation Status Management

The **Manage Status** module allows administrators to review donation submissions. A donation may be **approved** or **rejected** after the payment has been successfully verified.

## 1.5 Logout

To securely end the current administrative session, click the **Log Out** button.

---

# 2. User Portal

The **User Portal** enables users to browse NGO-related news, submit donations, track donation status, and manage their personal information.

## 2.1 Home

The **Home** page displays the latest news and updates related to NGO charity activities in **Raub, Pahang**.

## 2.2 Donation

The **Donation** page allows users to:

- Select a preferred donation location
- Enter the donation amount
- Submit the donation together with the required payment

## 2.3 Donation Status

The **Donation Status** page enables users to:

- View submitted donations
- Track the current donation status
- Monitor the progress of donation verification

## 2.4 Profile Management

To update your profile:

1. Navigate to the **Profile** page.
2. Select **Update Profile**.
3. Edit the required personal information.
4. Click the **Update** button to save the changes.
5. A confirmation message will be displayed upon successful completion.

## 2.5 Logout

Click the **Log Out** button to securely terminate the current user session.

---


- Administrator accounts are managed exclusively by the system administrator.
- Users are responsible for ensuring that all submitted donation information and payment details are accurate.
- Donations will only be approved after the payment has been successfully verified by the administrator.
